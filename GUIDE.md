# PUBG Challenge — Полная инструкция

## Что это

Electron-приложение для игры в PUBG с челленджами. Показывает текущее задание и активные наказания через прозрачный оверлей поверх игры. Управление — через отдельное контрольное окно.

---

## Запуск

```bash
npm install      # один раз
npm start        # запустить
```

При первом запуске автоматически создаются файлы данных в папке `%AppData%\pubg-challenge-overlay\` (Windows).

---

## Окна приложения

### Control Window (главное окно)

Основной интерфейс управления. Открывается при старте.

| Кнопка | Действие |
|---|---|
| 🎲 Новое задание | Выдать следующее задание (без выполнения/провала) |
| ✅ Выполнено | Засчитать выполнение, получить новое задание |
| ❌ Провалено | Засчитать провал, получить новое задание + добавить наказание |
| 📝 Редактор | Открыть редактор заданий |
| ⚙ Настройки | Открыть настройки оверлея |

**Текущее задание** — показывает название (жёлтым) и описание задания.

**Активные наказания** — список до 3 наказаний одновременно. У каждого есть кнопка «Закрыть» — нажми когда наказание выполнено/истекло.

**Счётчики** — общее количество выполненных и проваленных заданий за сессию.

---

### Overlay (оверлей поверх игры)

Прозрачное окно без рамки, всегда поверх всех окон включая полноэкранные игры.

Показывает:
- Текущее задание (название + описание)
- Активные наказания
- Счётчики выполнено/провалено

**Перемещение:** потяни за панель мышью — позиция сохранится автоматически.

**Изменение размера:** потяни за угол/край окна — размер тоже сохраняется.

**Точная позиция/размер:** задай вручную в настройках (кнопка ⚙ в Control Window).

> Оверлей работает поверх PUBG в безрамочном режиме. В настоящем фуллскрине (не безрамочный) — тоже должен отображаться, используется уровень `screen-saver`.

### Editor (редактор)

Открывается кнопкой 📝 Редактор. Три вкладки:

---

#### Вкладка: Задания

Список всех рукописных заданий.

Каждая запись содержит:
- **Название** — короткое, отображается крупным в оверлее
- **Описание** — подробности задания
- **Теги** — через запятую. Используются для конфликт-проверки (см. ниже)

Кнопки:
- `+ Добавить` — новое задание
- `✕` справа от записи — удалить задание

---

#### Вкладка: Наказания

Аналогично заданиям. Наказание добавляется автоматически при нажатии ❌ Провалено.

Каждая запись:
- **Название** — короткое
- **Описание** — подробности
- **Теги** — для конфликт-проверки

---

#### Вкладка: Генератор

Генератор создаёт задания на лету из шаблонов с подстановкой случайных значений.

##### Шаблоны

Шаблон — это заготовка задания с плейсхолдерами вида `{имя_пула}`.

Пример:
- Название: `Убийца с {оружие}`
- Описание: `Убить {количество} игрока(-ов) используя только {оружие}`
- Теги: `оружие`

При генерации `{оружие}` заменится случайным значением из пула `оружие`, например `дробовика`.

Результат: **«Убийца с дробовика»** / «Убить 2 игрока(-ов) используя только дробовика»

Каждый шаблон имеет:
- **Название** — шаблон с `{плейсхолдерами}`
- **Описание** — шаблон с `{плейсхолдерами}`
- **Теги** — работают так же как у рукописных заданий

##### Пулы значений

Пул — это именованный список слов/фраз. Имя пула используется в шаблонах как `{имя_пула}`.

Пример пула `оружие`:
```
пистолета
дробовика
снайперской винтовки
пистолета-пулемёта
```

Управление:
- `+ Добавить пул` — создать новый пул (имя можно переименовать)
- `+ Добавить значение` — добавить строку в пул
- `✕` у значения — удалить конкретное значение
- `✕ Удалить пул` — удалить весь пул

> Если в шаблоне используется `{пул}`, которого нет в списке пулов, в превью он покажется как `[пул?]` — это подсказка что нужно создать пул с таким именем.

##### Включить генератор

Чекбокс **«Включить генератор (50/50 с рукописными)»**:
- **Выключен** — выдаются только рукописные задания
- **Включён** — каждое новое задание с вероятностью 50% берётся из генератора, 50% — рукописное

##### Превью

Кнопка **🎲 Сгенерировать** — мгновенно показывает как будет выглядеть задание из текущих шаблонов и пулов. Сохранять не нужно, работает с несохранёнными данными.

---

#### Кнопки редактора (вверху)

| Кнопка | Действие |
|---|---|
| ✔ Сохранить всё | Сохранить все изменения (задания, наказания, шаблоны, пулы, настройки генератора) |
| 💾 Экспорт | Сохранить `tasks.json` в произвольное место на диске |
| 📂 Импорт | Загрузить `tasks.json` из файла (заменяет текущую библиотеку) |

## Конфликт-проверка

Когда программа выбирает следующее задание, она проверяет **теги** задания и **теги** всех активных наказаний.

Если совпадение есть — задание пропускается и берётся другое.

**Пример:**
- Активное наказание: «Без транспорта», теги: `транспорт`
- Задание: «Сигнальщик» (проехать с сигналом), теги: `транспорт`
- → Задание **не будет выдано** пока наказание активно

Чтобы это работало — нужно правильно расставлять теги в заданиях и наказаниях через запятую. Теги свободные, придумываешь сам.

---

## Экспорт / Импорт (обмен заданиями с другом)

1. Открой редактор → нажми **💾 Экспорт** → выбери куда сохранить
2. Отправь другу файл `pubg-tasks.json`
3. Друг открывает редактор → нажимает **📂 Импорт** → выбирает файл

Файл содержит все задания, наказания, шаблоны и пулы генератора.

## Настройки оверлея

Открываются кнопкой ⚙ в Control Window.

| Поле | Описание |
|---|---|
| X / Y | Позиция оверлея на экране в пикселях от левого верхнего угла |
| Ширина / Высота | Размер окна оверлея в пикселях |

Позицию и размер также можно менять напрямую мышью — потянуть/растянуть оверлей. Сохраняется автоматически.

## Структура файлов данных

Файлы хранятся в `%AppData%\pubg-challenge-overlay\` (Windows).

| Файл | Содержимое |
|---|---|
| `tasks.json` | Задания, наказания, шаблоны, пулы |
| `state.json` | Текущее состояние (активное задание, наказания, счётчики, настройки) |

---

## Структура tasks.json

```json
{
  "tasks": [
    {
      "id": 1,
      "title": "Название задания",
      "description": "Подробное описание",
      "tags": ["тег1", "тег2"]
    }
  ],
  "curses": [
    {
      "id": 101,
      "title": "Название наказания",
      "description": "Подробное описание",
      "tags": ["тег1"]
    }
  ],
  "generatorEnabled": false,
  "pools": {
    "оружие": ["пистолета", "дробовика", "снайперки"],
    "количество": ["1", "2", "3"]
  },
  "templates": [
    {
      "id": 1,
      "title": "Убийца с {оружие}",
      "description": "Убить {количество} игрока используя только {оружие}",
      "tags": ["оружие"]
    }
  ]
}
```

## Сброс прогресса

Настройки ⚙ → кнопка **🗑 Сбросить прогресс** — обнуляет счётчики выполненных/проваленных. Задания и наказания не затрагиваются.
